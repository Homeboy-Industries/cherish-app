# Cherish: Homeboy Industries Supporter App (Prototype)

A mobile-first web app prototype for Homeboy supporters. It runs in iPhone Safari and can be added to the home screen.

> **Prototype only.** Every story, impact figure, event, product and price is sample content. No payments are taken and no form data is sent anywhere. Real participant stories need the person's written consent before they're published.

## What's in it
- **Home**: giving summary, quick actions, featured story, next event
- **Give**: monthly or one-time gifts, preset and custom amounts, where the gift goes, mock checkout
- **Daily Thought**: Thought of the Day YouTube playlist
- **Stories**: story list and full-page view (placeholder text)
- **Events & volunteering**: RSVPs, filters, volunteer interest form
- **Shop**: Homeboy social enterprise products with a cart and mock checkout

## Run it
Open `index.html` in any browser. It's one file with no build step.

On iPhone: open the hosted page in Safari → Share → **Add to Home Screen**.
